---

## 1. Authoritative Status Definitions

- **NOT IMPLEMENTED:** Capability is planned or specified but no code exists.
- **INCOMPLETE:** Preliminary code or UI stub exists, but required backend or interactions are missing.
- **IMPLEMENTED - NOT VERIFIED:** Code and backend are complete and compile cleanly, but await runtime verification or hardware testing.
- **VERIFIED IN DEV MOCK:** Verified with isolated deterministic fictional mock data in development environment.
- **VERIFIED IN REAL USER:** Verified against genuine user profile, real sources, and persistent disk storage without fabricated data.
- **VERIFIED IN INSTALLED DEVELOPMENT BUILD:** Verified running in an installed development binary on desktop.
- **VERIFIED IN RELEASE BUILD:** Verified in standalone production release package (.rpm / AppImage).
- **BLOCKED - EXTERNAL DEPENDENCY:** Blocked by missing hardware, external platform runner, or explicit product owner authorization.
