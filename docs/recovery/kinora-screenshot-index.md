# Kinora Complete Screenshot Index and Visual Parity Catalog

## 1. Overview

As part of Kinora v0.5.1 recovery acceptance, two permanent, comprehensive screenshot libraries and a side-by-side comparison gallery were generated. Every view has been captured in two distinct environments under identical desktop dimensions (1920x1080 baseline and 1280x800 responsive):

1. **Dev Mock (`docs/ui/dev-mock/`)**: Deterministic development fixtures demonstrating all media formats, interactive states, and edge conditions.
2. **User Sources (`docs/ui/user-sources/`)**: The actual user profile environment, populated with genuine configured sources (35 M3U playlists, 14,633 channels, 14 EPG feeds) and verified Public Discovery cultural archives.
3. **Comparison Gallery (`docs/ui/comparison/`)**: 25 side-by-side composite images (Dev Mock on left, User Sources on right) providing visual evidence of structural parity.
